# Лабораторная работа №1

Для запуска нужен Linux (можно WSL), Bash 4.4+, git, awk, grep и flock.
Команды ниже выполняются из корня репозитория.

## Сравнение веток

```bash
bash lab1/branch_diff.sh https://github.com/example/project.git main develop
```

Принимает ссылку на репозиторий и имена двух веток. Создает в текущей
папке `diff_report_main_vs_develop.txt` со списком файлов и количеством
добавлений, удалений и изменений. Сравнение идет от первой ветки ко второй.
Переименование учитывается как удаление и добавление.
Если в имени ветки есть `/`, в имени отчета он заменяется на `%2F`.

## Мониторинг системы

```bash
bash lab1/system_monitor.sh START
bash lab1/system_monitor.sh STATUS
bash lab1/system_monitor.sh STOP
```

START запускает монитор в фоне и выводит PID, STATUS проверяет состояние,
STOP останавливает процесс. Повторный START не создает второй экземпляр.

Первая запись появляется через секунду, остальные — каждые 10 минут.
Отчеты сохраняются в папке запуска: `system_report_YYYY-MM-DD.csv`.

```text
timestamp;all_memory;free_memory;%memory_used;%cpu_used;%disk_used;load_average_1m
```

Память указана в КиБ. Свободная память берется из MemFree, поэтому кеш
считается занятой памятью. Загрузка CPU измеряется за секунду, idle и iowait
считаются простоем. Для диска берется раздел `/`.

PID и журнал ошибок находятся в
`${XDG_STATE_HOME:-$HOME/.local/state}/lab1-monitor/<идентификатор>/`.
Все команды управления нужно запускать от одного пользователя.

Для быстрой проверки можно уменьшить интервал:

```bash
MONITOR_INTERVAL_SECONDS=2 bash lab1/system_monitor.sh START
bash lab1/system_monitor.sh STOP
```

## Поиск в логах

```bash
bash lab1/log_errors.sh example.log ERROR
```

Ищет строки с указанным словом с учетом регистра. Спецсимволы считаются
обычным текстом. Количество выводится в терминал.
В новой папке `log_report.XXXXXX` создаются два файла:

- `errors.txt` — найденные строки;
- `count.txt` — их количество.

Несколько совпадений в одной строке считаются за одну строку.
Если совпадений нет, счетчик равен 0, а файл со строками пустой.
